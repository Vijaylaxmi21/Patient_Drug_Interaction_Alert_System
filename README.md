# 💊 Patient Drug Interaction Alert System

## 📌 Project Overview

The Patient Drug Interaction Alert System is a menu-driven application developed using the C programming language.

It demonstrates how potential drug-drug interactions can be identified by checking combinations of medicines stored in a sample drug database.

The system displays interaction severity levels and provides educational alternative candidates based on therapeutic class.

## ✨ Features

- Drug Database Management
- Pairwise Drug Interaction Checking
- Interaction Severity Classification
- Alternative Drug Suggestions
- Dynamic Database Updates
- Memory Management
- Interactive Command-Line Menu

## 🛠️ Technologies Used

## ⚙️ How to Run the Project

**Step 1: Compile the program**

```bash
gcc main.c -o main
```

**Step 2: Run the program**

For Windows:

```bash
main.exe
```

For Linux:

```bash
./main
```

## 📋 Main Menu

The application provides the following options:

1. Display Drug Database
2. Check Drug Interactions
3. Suggest Alternatives
4. Add New Drug
5. Add New Interaction
0. Exit
